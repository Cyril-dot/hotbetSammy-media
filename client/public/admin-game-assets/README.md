# HotBet Admin Game Logo Library

This asset pack contains 60 transparent team-style crests for the Super Admin match creator: 30 home-team options in `home/` and 30 away-team options in `away/`. The assets use the HotBet orange, black, graphite, and white visual system and are suitable for `homeLogo` and `awayLogo` fields in admin match creation.

Use paths such as `/admin-game-assets/home/home-01.png` and `/admin-game-assets/away/away-01.png` when configuring admin-created fixtures.
